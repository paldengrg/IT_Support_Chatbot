# Installing and Uninstalling Software

## Approved software only
Only install software approved by IT. To request new software, submit a request through the IT portal.

## Install on Windows
1. Open Company Portal from the Start menu.
2. Find the application and select Install.
3. If the app is not listed, submit a software request through the IT portal.

## Uninstall on Windows
1. Open Settings > Apps > Installed apps (Windows 11) or Settings > Apps > Apps & features (Windows 10).
2. Find the app, select the … menu (Windows 11) or the app name (Windows 10), then Uninstall.

## Install and uninstall on macOS
1. Install approved apps from Self Service or the App Store.
2. To uninstall, open Finder > Applications and drag the app to the Trash, or use the app's own uninstaller if it has one.

## Administrator rights
Some installations require administrator authorization. If you are asked for an administrator password you do not have, contact IT Support at support@example.com.
