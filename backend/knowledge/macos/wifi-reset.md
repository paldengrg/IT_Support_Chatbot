# macOS: Fix Wi-Fi Problems

## Quick fixes
1. Click the Wi-Fi icon in the menu bar and turn Wi-Fi off, wait 10 seconds, then turn it on.
2. Restart the Mac from the Apple menu > Restart.

## Forget and rejoin the network
1. Open the Apple menu > System Settings > Wi-Fi.
2. Next to the network name, click the Details button (or the … button) and choose Forget This Network.
3. Select the network again and enter the password.

## Run Wireless Diagnostics
1. Hold the Option key and click the Wi-Fi icon in the menu bar.
2. Choose Open Wireless Diagnostics and follow the prompts.

## Still not working
Check whether other devices can connect. If none can, the problem is likely the network itself; contact IT Support at support@example.com.
