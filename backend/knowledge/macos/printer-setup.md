# macOS: Add a Printer

## Add a printer (macOS Ventura and later)
1. Open the Apple menu > System Settings > Printers & Scanners.
2. Click Add Printer, Scanner, or Fax.
3. Select the printer from the list and click Add.

## Add a printer (macOS Monterey and earlier)
1. Open the Apple menu > System Preferences > Printers & Scanners.
2. Click the + button below the printer list.
3. Select the printer and click Add.

## Printer not listed
1. Make sure the Mac and the printer are on the same network.
2. Turn the printer off and on again.
3. If you know the printer's IP address, click the IP tab (globe icon) in the Add window and enter it.

## Reset the printing system
If jobs are stuck or the printer shows an error, Control-click inside the printer list in Printers & Scanners and choose Reset printing system. This removes all printers, so add them again afterwards.
