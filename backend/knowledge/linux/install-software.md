# Linux: Install and Remove Software

## Ubuntu and Debian
1. Open a terminal.
2. Refresh the package list: `sudo apt update`
3. Install a package: `sudo apt install <package-name>`
4. Remove a package: `sudo apt remove <package-name>`

## Fedora
1. Open a terminal.
2. Install a package: `sudo dnf install <package-name>`
3. Remove a package: `sudo dnf remove <package-name>`

## Notes
Commands starting with `sudo` need administrator rights. On company-managed Linux machines, administrator authorization may be required; contact IT Support at support@example.com if you do not have `sudo` access. Only install software approved by IT.
