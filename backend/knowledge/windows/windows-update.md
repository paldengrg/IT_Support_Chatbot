# Windows Update Troubleshooting

## Check for updates
1. Open Settings > Windows Update (Windows 11) or Settings > Update & Security > Windows Update (Windows 10).
2. Select Check for updates.
3. Install any available updates and restart when asked.

## Updates fail or get stuck
1. Restart the computer and try again.
2. Make sure at least 10 GB of disk space is free: open Settings > System > Storage.
3. Run the troubleshooter. Windows 11: Settings > System > Troubleshoot > Other troubleshooters > Windows Update > Run. Windows 10: Settings > Update & Security > Troubleshoot > Additional troubleshooters > Windows Update.
4. Restart again and select Check for updates.

## Still failing
Write down the error code shown (for example 0x80070002) and send it to IT Support at support@example.com. Some updates on company devices are managed by IT and may require administrator authorization.
